# Sprite del enemigo navajero

`sprite_navajero.png` proviene de [2D Pixel Art Knife Man](https://ozanimations.itch.io/knifeman), de Ozanimations. La página lo ofrece gratis y lo describe para usar en juegos; incluye caminar y una animación con navaja.

La hoja de caminata descargada tiene diez cuadros de 32 × 32 px. El proyecto usa los dos cuadros de paso distintos. El archivo separado de ataque anunciado en la página no se pudo descargar desde itch, así que el enemigo muestra una navaja sencilla durante el golpe.

El juego carga `sprite_navajero_sin_fondo.png`, una copia con el fondo exterior transparente y el mismo tamaño de 320 × 32 px.

La página no especifica una licencia detallada. Se conserva el nombre del autor y la fuente para atribución y consulta.
