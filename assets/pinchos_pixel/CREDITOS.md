# Pinchos pixel art

**Spike trap**, Environment Pack de **SpritePilot**.

- Fuente: https://spritepilot.com/free-game-assets/environment
- Descarga original: https://spritepilot.com/free-assets/environment/spike-trap-32px_strip8.png
- Licencia: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Se conserva el PNG original. Godot recorta las puntas y la placa como AtlasTexture, las orienta horizontalmente y adapta el alcance a la separación del recurso `.tres`. La tonalidad cian se aplica mediante `modulate` para acompañar el escenario.
