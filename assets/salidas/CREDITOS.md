# Salidas de nivel

**Cave Entrance**, de Jordan Irwin / **AntumDeluge**, licencia [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

- Fuente: https://opengameart.org/content/cave-entrance-0
- Original: https://opengameart.org/sites/default/files/cave_entrance_0.png
- Se usa la primera entrada de la hoja mediante una región, sin modificar el PNG.

**Portals 32 x 48**, de **RodHakGames / RHG**, licencia CC0 1.0.

- Fuente: https://opengameart.org/content/portals-32-x-48
- Original: https://opengameart.org/sites/default/files/portalsSpriteSheet.png
- Se animan cuatro cuadros de cada color mediante regiones de 32 × 48. Oro para el bosque verde, azul para el celeste y rojo para el rojizo.

La escena reutilizable `res://piezasEscenario/salida/SalidaNivel.tscn` tiene el origen sobre el suelo y contiene tanto el aspecto visual como la zona que completa el nivel. Se coloca directamente en las escenas.
